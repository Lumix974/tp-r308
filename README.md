
# TP R3.08 - Programmation Python

Travaux pratiques de programmation Python du BUT 2 Réseaux et Télécommunications.

## Prérequis

- Python 3.10 ou supérieur
- Aucune bibliothèque externe nécessaire

## TP1 - Gestion de données et mini-jeux

Le TP1 comprend :
- Un dictionnaire d'étudiants
- Un jeu de devinette
- La manipulation de mots
- Le jeu du Pendu et ses bonus

Lancement :

    py tp1/partie_d.py

## TP2 - Jeu du Morpion

Le TP2 comprend :
- La classe Grille
- Les joueurs humains et IA
- Un jeu complet
- Une IA améliorée

Lancement :

    py tp2/partie_c.py

## TP3 - Gestion d'une bibliothèque

Le TP3 comprend :
- Les classes Livre et Utilisateur
- La gestion des emprunts
- La sauvegarde CSV
- Un menu interactif
- Des statistiques et des extensions

Lancement :

    py tp3/partie_d.py

## Tests du TP3

    py tp3/test_bonus.py

## Remarques

Les commandes ci-dessus sont destinées à Windows.

Sous Linux ou macOS, remplacer `py` par `python3`.

Les fichiers de sauvegarde du TP3 sont créés dans le dossier `tp3`.
